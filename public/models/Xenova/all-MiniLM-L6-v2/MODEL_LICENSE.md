# all-MiniLM-L6-v2

This directory contains the quantized ONNX export and tokenizer files for
`Xenova/all-MiniLM-L6-v2`, derived from
`sentence-transformers/all-MiniLM-L6-v2` and distributed under the Apache-2.0
license.

- Model: https://huggingface.co/Xenova/all-MiniLM-L6-v2
- Base model card: https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2
- License: https://www.apache.org/licenses/LICENSE-2.0
